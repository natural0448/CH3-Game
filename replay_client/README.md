# 작은 마을 움직임 리플레이

`start.cmd`를 더블 클릭하거나 PowerShell에서 실행합니다.

```powershell
cd C:\MLO01-01\Chapter3\Game-server\replay_client
.\start.cmd
```

브라우저에서 http://127.0.0.1:8766/ 이 열립니다. 실행한 터미널에서 Ctrl+C를 누르면 종료됩니다. Django·Kafka·Spark는 필요하지 않습니다. Python 표준 라이브러리만 쓰며 기존 Game-server 가상환경 Python을 실행합니다.

## 조작

- 방 선택: 해당 방의 기록을 처음부터 재생합니다.
- 재생/일시정지: Space 또는 재생 버튼. 마지막에 도착하면 다시 재생할 수 있습니다.
- 이전/다음 행동: 좌우 버튼 또는 방향키. 첫 장면/마지막 장면 버튼도 있습니다.
- 타임라인: 원하는 행동까지 즉시 이동합니다. 되감으면 동전·좌표·버전도 그 시점으로 복원합니다.
- 배속: 0.5, 1, 2, 4, 8배.
- 긴 대기 줄이기: 기본 켜짐. 이벤트 간격을 0.12~1.2초로 표시합니다. 꺼두면 원래 발생 시각 간격을 따릅니다. 며칠 동안 행동이 없는 구간도 있으므로 기본 설정을 권장합니다.
- 캐릭터 선택: 해당 플레이어의 최근 이동 경로를 강조합니다. 모든 좌표·동전 값은 저장된 행동 결과입니다.

## 데이터와 제한

기본 입력은 `../data-replay/raw/game-events.jsonl`입니다. 파일을 읽어 event_id 중복을 제거한 뒤 발생 시각순으로 재생합니다. 같은 event_id에 서로 다른 내용이 있으면 조용히 덮어쓰지 않고 오류를 표시합니다.

첫 기록 이전 위치, 로그인·로그아웃, 캐릭터 이름은 이 파일에 없습니다. 따라서 첫 행동부터 캐릭터를 표시하고 이름 대신 player_id를 사용합니다. 캐릭터는 마지막 기록 위치에 남아 있으며 이것은 현재 접속 상태가 아닙니다. 배경 장식은 기존 Game-client 에셋을 재사용했습니다.

낮은 버전의 늦게 도착한 이벤트는 이미 재현한 새 상태를 되돌리지 않습니다. 보상이나 충돌을 새로 계산하지 않고 payload의 x/y/coins/version을 그대로 복원합니다. 한 타일의 연속 이동만 짧게 보간하며, 기록이 건너뛰면 관측 위치로 바로 표시합니다.

실행 시 원본을 다시 읽고 `data.js`를 갱신합니다. 원본, DB, Kafka topic/consumer offset은 변경하지 않습니다. 데이터 갱신 후 브라우저를 새로고침하세요.

서버 없이 열려면 이미 생성된 `index.html`을 더블 클릭해도 됩니다. 이 경우 마지막 생성 시점의 자료를 사용합니다. 자료만 갱신하는 명령:

```powershell
..\server\.venv\Scripts\python.exe main.py --build-only
```

다른 JSONL이나 포트를 사용하려면:

```powershell
..\server\.venv\Scripts\python.exe main.py --source "원본.jsonl" --port 8767 --open
```
